# 五間日照・共用室內散策預覽

大和保留 `?scene=dahe`；安南、龍山、義合、新營使用 `?scene=interior&center=annan|longshan|yihe|xinying`（擇一 ID）。城市五間建築均有「進入室內」，室內入口均有「返回戶外」。`CenterInteriorEntrances.tsx` 共用入口渲染，位置跟隨各館原本座標／朝向；`centers.ts` 管理館名、門口局部定位、網址與儲存 key，不複製人物、家具或控制系統。

其餘四館沿用大和的遊戲配置，頁面與參觀文案明確標示共用示意，並非各館實景。各館進度分開：大和沿用 `lohas-rush:dahe-preview:v1`，其餘為 `lohas-rush:<館 ID>-preview:v1`；重新參觀只重設目前館。室內頁仍不初始化城市存檔 store；從任一館城市入口進入後，返回原本的車位與主線進度。

入口：`?scene=dahe`。即時預覽使用 `http://127.0.0.1:5227/?scene=dahe`，以 `npm.cmd run dev -- --host 127.0.0.1 --port 5227 --strictPort` 啟動，不啟用離線快取。正式建置測試可用 `5226`；其 PWA 更新需關閉同來源所有遊戲視窗，重新整理不保證啟用已下載的新版。

城市中靠近大和園區時，門口顯示「進入室內」連結，可用滑鼠、觸控或鍵盤 Enter 開啟此獨立場景；角色從入口地墊開始探索。連結跳轉前保存城市旅程，「返回城市」可從原車位與主線進度繼續。此為頁面連結，尚未加入下車步行或無縫回車的模式切換；主遊戲沿用既有五站任務與接送系統。

室內靠近入口地墊時，門口另有「返回戶外」連結，同樣支援滑鼠、觸控與鍵盤 Enter；從城市大和門口進入後可回到原停車位置。離開入口、俯瞰或開啟參觀對話時隱藏門口連結，頂部「返回城市」持續保留。

## 操作與進度

- 五館皆可自由環景：滑鼠左鍵或右鍵拖曳／手機單指滑動，水平可轉滿 360°、上下角度有界限；滾輪／雙指開合縮放，距離限制 4～14 個遊戲單位。按住場景與觸控方向鍵可同時轉動及移動。
- 「重設視角」只回復預設鏡頭，保留奶奶位置與進度。鬆開拖曳後保留選定角度；奶奶移動方向配合視角，角色轉身不會強制轉動鏡頭。R 回入口並重設鏡頭；俯瞰切換回預設角度，對話期間暫停鏡頭輸入。失焦、旋轉螢幕或取消觸控會釋放拖曳。
- 操控老奶奶輪椅：WASD／方向鍵移動，Shift 加快，Space 停下；手機可按住畫面方向鍵，支援雙指組合。
- 靠近光圈按 E 或「看看這裡」，Esc／「繼續散策」關閉。互動及俯瞰期間暫停步行，切換、失焦、頁面隱藏與視窗旋轉釋放輸入。
- 順序為迎賓接待 → 共聚活動 → 悠閒休憩 → 溫暖備餐 → 扶手練習；每區需確認才記錄，重讀不重複計數。
- R 只讓這個預覽的角色回入口；「重新參觀」需再次確認，才重設預覽進度。
- 每館使用上述獨立 key，格式為 `{version:1,completed:0..5}`。不讀寫城市旅程或探索日記；較新版本原始紀錄保留，儲存受限時仍可參觀。

## 沿用的模組

- `passengerModels.ts`：沿用既有老奶奶與輪椅造型，縮放與城市乘客相同為 .9，不新增另一套人物模型。
  2026-11-27 已將原本整圈膨出的站姿裙形修正為貼合坐墊、沿大腿與膝前彎曲垂落的坐姿裙襬，補順膝腿銜接；五館與城市共用此修正，輪椅及碰撞範圍沿用原設定。
- `StreetNavigation.ts`：現有行人圓形／掃掠碰撞；半徑 .44 包含老奶奶及輪椅在所有朝向的範圍。
- `cameraCollision.ts`：現有線段／包圍盒鏡頭避障。
- `MouseOrbit.ts`：沿用城市既有的環繞、俯仰與縮放運算。`interiorCamera.ts` 僅替室內 Canvas 接上滑鼠／觸控輸入及視角相對移動，未修改城市鏡頭；鏡頭目標固定於奶奶，避障在插值前後都套用。
- React Three Fiber、drei、Three.js 與既有材質合併工具；無新增套件。

`interior.ts` 定義家具、碰撞與互動點；`DaheInterior.tsx` 負責獨立 Canvas、步行及參觀介面；`dahe.css` 只作用於預覽。獨立預覽的局部輸入與進度尚非正式城市整合方案，不掛接第二套城市任務 store。正式版入口以延遲載入避免預覽啟動城市存檔事件。

## 驗證方式

```powershell
npm.cmd test
npm.cmd run build
# 另開終端機執行 npm.cmd run preview -- --host 127.0.0.1 --port 5226 --strictPort
$env:TEST_BASE_URL = 'http://127.0.0.1:5226/'
npm.cmd run test:dahe
npm.cmd run test:interiors
npm.cmd run test:pwa
```

環景鏡頭測試會讀取開發版 R3F 場景，請另外啟動 `5227` 開發伺服器後執行：

```powershell
$env:TEST_BASE_URL = 'http://127.0.0.1:5227/'
npm.cmd run test:interior-camera
```

預覽測試以真實鍵盤／觸控操作，結果與截圖在 `.test-artifacts/dahe/`。PWA 測試另驗證根／子目錄離線開啟預覽。碰撞與鏡頭仍為幾何近似，未驗證真實手機、Safari／iOS、建築尺寸或無障礙設計規範。
